Reproducibility

Verification and provenance

The library and its independent statement compile with Lean 4.35.0-rc3. Their axiom reports contain only propext, Classical.choice, and Quot.sound. The three deliberate Challenge placeholders are not part of the proof.

{{verification_status}}

Build the project

lake exe cache get
lake build
python3 scripts/audit_axioms.py
python3 scripts/scan_axioms.py
python3 scripts/generate_challenge.py --check
lake build Challenge Solution

A fresh build takes about 50 minutes on 20 hardware threads. Build Challenge Solution before independent comparison with scripts/verify-comparator.sh.

What has been reviewed

No human expert or independent agent has checked the Lean statements or the two proofs in docs/proofs. Lean checks the proofs; the match between Challenge.lean and the paper is a human judgement.
